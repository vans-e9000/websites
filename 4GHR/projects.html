Delivery sequence

From site review to completion record.

The sequence is set before mobilisation so the site team, the other trades, and the client work to the same dates.

01

Site and scope review

Access, existing services, occupied areas, and the work that must be protected are recorded.

02

Package definition

The scope, interfaces, responsibilities, and documentation are confirmed with the project team.

03

Coordinated delivery

Materials, labour, testing, and access are scheduled against the main programme.

04

Completion records

Test results, as-built notes, and outstanding items are issued at handover.

Project questions

Useful answers before mobilisation.

Does this page list completed projects?

This page sets out the sectors and scopes 4GHR takes on. Project references are shared on request once the scope and client permission are confirmed.

Can 4GHR work inside a main contractor's programme?

Yes. The package is set against the main programme, with access, hold points, and handover dates agreed before mobilisation.

How are interfaces with other trades priced?

Interfaces are listed in the scope with the assumed division of responsibility. The priced scope states what 4GHR provides and what must come from other parties.

What if the drawings are incomplete?

Send what exists. We identify the missing information, price the defined work, and note the items that need a decision before work starts.
