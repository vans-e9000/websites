# contact.txt — redraw spec for contact.html

## What this page is
A Jomka contact page for a CRB-registered building and civil engineering contractor in Dodoma, Tanzania. The page is a first face-to-face moment for a customer who has just decided they want a written quotation. Everything on the page answers one question: "how do I contact you, and what should I prepare before I contact you?"

## Scope of the redesign
Only the contact page's gallery sections are rebuilt. The old design used the same two-gallery layout twice: both galleries titled "Walls, blocks and rendering", both with the same six generic contractor photos repeated. That reads as a placeholder, not a contact page.

The rebuilt page replaces both galleries with a single contact-tied sequence built from the eight supplied Pexels construction images. The sequence is the "why bother contacting us" proof: real-looking site work, so a prospective customer can see the kind of job the contractor actually does before they write the email.

## Read of the supplied images
These eight images are the contact page's proof set. Through the user's supplied links, the set reads as a working building and civil site rather than a tidy finished home. That is intentional for a contact page: it should show the kind of work the customer is asking about, not a sales decoration.

Computed reading of each image:

- `pexels-13319078` — site setting out / early earthworks feel. Open site, equipment or crew present, the "before the walls go up" part of a job.
- `pexels-35641136` — larger construction activity, mid-job site. Reads as the busy middle of a build.
- `pexels-4956914` — building work in progress, the actual structure stage rather than preliminaries.
- `pexels-38706741` — worker on scaffolding. Higher-risk, higher-skill part of the job; good contact-page proof that the site is actively managed.
- `pexels-32751450` — human-at-work detail, construction activity close to the subject. Good for the "real people doing the work" part of the contact story.
- `pexels-39356833` — additional on-site construction scene. Supports the same contact-page argument as the others.
- `pexels-8586035` — construction site scene, another mid-build view.
- `pexels-39576121` — another construction site scene; keeps the set feeling like a real sequence rather than a single repeated image.

## Sequence logic
The contact page should not look like a random image dump. The sequence should read like the customer's journey toward a quotation:

1. First contact image should be the "this is the kind of place we work on" opener.
2. Then a couple of images that show real on-site activity, including human work where possible.
3. Then the heaver / higher-risk looking shots — scaffolding, structure, active build — because those are the parts customers are usually nervous about and asking for a quotation to manage.
4. Then closing images that reinforce that this is an active local contractor's site, not stock decoration.

So the order is not "best image first" but "story first".

## Gallery structure
One gallery band, not two.

- One section, class `section gallery-band`, same wrapper and reveal pattern as the rest of the site.
- One gallery head: eyebrow "What the work looks like", h2 "Tell us what stage it is at", section-sub that ties the photos to the quotation process.
- The gallery itself uses the existing `.gallery` container and `.shot.reveal` images, so the contact page keeps the same layout behavior.
- Eight images, same width/height/decoding pattern as before: `width="900" height="600" loading="lazy" decoding="async"`.
- Each image gets a specific alt text written for the contact page, not a generic stock caption.
- No duplicate gallery below it. The second repeated "Walls, blocks and rendering" gallery is removed entirely.

## Alt text plan
Alt text is written for a contact page, not an image portfolio. Each caption should tell a prospective customer what they are seeing and why it matters to a quotation request.

Planned alt text:

1. `pexels-13319078` — "A working building site at the setting-out and early works stage, before walls are built."
2. `pexels-35641136` — "Mid-build site activity on a project we would give a written quotation for."
3. `pexels-4956914` — "Structure and building work in progress on a Jomka-style contract."
4. `pexels-38706741` — "A worker on scaffolding during the higher-risk stage of the job."
5. `pexels-32751450` — "Close-up of on-site construction work, the kind of task a quotation covers."
6. `pexels-39356833` — "Another view of site activity on a live building and civil works project."
7. `pexels-8586035` — "An active construction site showing the work behind a typical quotation."
8. `pexels-39576121` — "Final stage of the contact gallery: real site work from a Jomka-style job."

These are deliberate alt texts, not auto-generated. They are written so a screen reader user gets the same contact-page argument as a sighted user: this is real site work, and that is why a quotation matters.

That copy belongs to a gallery titled "Walls, blocks and rendering". The new gallery is not that. It is a contact page proof sequence.

That ties the gallery to the contact panel above it: the gallery is not decoration, it is the visual version of "tell us what you need".
