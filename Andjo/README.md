# Andjo Engineering website

A static, multipage contractor website for Andjo Engineering Company Limited. The design follows the attached Renderly reference, with a white canvas, orange display surfaces, blue interactive controls, a sticky six-item navigation and prose-led editorial layouts. Each route features relevant illustrative Pexels photography from an African context or construction setting.

## Local preview

From this project folder, run `node build.mjs`, then `node server.mjs`. The preview binds to `127.0.0.1:3000` by default. Set the `PORT` environment variable only if the Webdev Session declares a different port. The initialized project preview is currently available at the local Webdev address.

## Production SEO origin

Before a production build, set `SITE_URL` to the company’s confirmed primary HTTPS origin. The build then emits absolute canonical URLs, Open Graph URLs, `sitemap.xml` and `robots.txt`. It deliberately omits guessed canonical origins when no public domain has been confirmed. Set the environment variable to the origin alone, without a path, credentials, query or fragment.

## Company facts and imagery

The [source register](SOURCES.md) records the live CRB search result, the matching Building (`/show/623`) and Civil (`/show/624`) entries, the checked date, the public-status limitation and each Pexels photographer/source page. Every stock photograph is identified as illustrative and is not presented as Andjo project work or staff. Images load from the Pexels CDN at responsive widths; hero images load eagerly and secondary page images use browser-native sizing.

Company records reviewed on 31 October 2026 do not show a separate expiry date or active-status field. Procurement teams should consult the live CRB register when current standing or a tender-specific condition must be confirmed.

## Contact and quote enquiry

The quote form validates the entered project details and composes an email to the address published on the CRB record. It uses the visitor’s configured email application rather than submitting to a hosted CRM or server endpoint.

## Structure

- `build.mjs` renders the static HTML pages and origin-dependent SEO files.
- `styles.css` contains the Renderly-based layout, typography, palette and responsive rules.
- `script.js` handles the accessible mobile navigation, restrained reveal motion and quote enquiry.
- `manus-routes.json` declares all crawlable pages.
- `dist/` is regenerated by the build and is the static deployment output.
