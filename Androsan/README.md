# Androsan website

Plain local multipage website for Androsan, a Tanzania-focused civil works and construction contractor.

## Pages

- `index.html` Home, service areas and project brief checklist
- `services.html` Civil works, building works and project coordination scope
- `projects.html` Work areas and portfolio information requirements
- `about.html` Delivery approach and client responsibilities
- `contact.html` Expanded project intake form

## Run locally

From this folder, run:

```powershell
.\serve.ps1
```

Then open `http://127.0.0.1:4173`.

## Content decisions

The site uses specific construction language without inventing Androsan project names, clients, contract values, registration details or contact details. The Work areas page explains what is needed before verified portfolio case studies are published.

The contact form confirms the enquiry on screen. Connect it to Androsan's approved email or enquiry system before public launch.

## Visual direction

The supplied Growmark direction is reflected in the light canvas, dark ink, rounded surfaces, lime accent, display typography, spacious sections, responsive layout and reduced-motion support. The copy uses a more technical contractor voice than the reference template.

## Image assignments

Each page uses a distinct image set. Images were sourced through image search and are intentionally not repeated between pages:

- Home: construction site image
- Services: workers and infrastructure images
- Work areas: four unique infrastructure and construction images
- About: Tanzania landscape / built environment image
- Contact: no decorative image, keeping the enquiry action focused
