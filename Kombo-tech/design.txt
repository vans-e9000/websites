# Imprint - Modern co-branded credit cards — Style Reference
> Extracted 2026-10-28 from https://imprint.co/?ref=minimal.gallery

**Theme:** light

Imprint - Modern co-branded credit cards (imprint.co) reads as a light, layered interface built on a UniversalSans-500 Regular/sans-serif type pairing. Structurally it relies on fully-rounded pill shapes as its signature geometry, and soft shadows lift key surfaces off the canvas — with a restrained, near-monochrome accent strategy. Motion is measured and smooth, averaging 200ms on interactive transitions. Typography runs from 12px up to 116px across 6 steps, and the spacing system sits on a 4-unit base with 24px container padding.

## Do's and Don'ts

### Do
- Use `#efefef` as the canvas and build every surface from the token table above — never invent intermediate grays
- Snap all spacing to the 4px base unit grid
- Use fully-rounded (pill, 9999px) radii for buttons and tags
- Default interactive transitions to 200ms with the extracted easing tokens

### Don't
- Do not introduce colors outside the 7-token palette extracted above
- Do not add springy/bounce motion — the source uses the timing functions listed under Tokens — Motion
- Do not stack multiple shadows — keep elevation minimal and let whitespace separate content

## Responsive Behaviour

**Strategy:** desktop-first (`max-width` queries strip down) — 0 min-width rules, 26 max-width rules, 20 range rules.

**Ladder:** the 2 breakpoints match no standard scale — they are custom to this site.

### Breakpoint matrix

| Tier | Query | Layout | Spacing | Type | Hidden / shown |
|---|---|---|---|---|---|
| md only | `810–1280px` | 2 col | padding-bottom 50px | — | — |
| <md | `≤810px` | 6→1 col | space +38% | — | — |

Across the 2 stops the ladder rewrites 134 declarations in 46 rules, the heaviest being `<md` at 81. Nothing else moves — anything not in the matrix above holds at every width.

### Mobile adaptation

- **Grid collapse:** 1 grid drops to a single column and 1 flex row turn into columns.
- **Spacing:** shifts +38% at mobile widths — padding and gaps grow by roughly that much, not to an arbitrary smaller value.

### Modern CSS in play

- **Container queries** are in use — components size to their container, not the viewport. Port the `@container` rules or the layout will not match at intermediate widths.
- **`aspect-ratio`** holds media boxes instead of padding hacks.
- **Intrinsic grids** — `auto-fit` / `minmax()` do the column maths instead of breakpoints.

**Fluid type:** sizes interpolate with `clamp()` / viewport units rather than stepping at breakpoints.

_Caveats: 2 declared breakpoint values had no capturable declarations (cross-origin or nested stylesheets)._
